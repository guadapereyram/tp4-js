# TP4 JavaScript

Trabajo práctico de JavaScript orientado a Programación Orientada a Objetos.

## Contenido

Este repositorio contiene la resolución de ejercicios prácticos vinculados a:
- creación de objetos
- propiedades y métodos
- uso de `this`
- validaciones
- arrays de objetos
- lógica básica aplicada a objetos

## Ejercicios

1. **Auto**  
   Objeto con propiedades básicas y métodos para encender y apagar.

2. **Cuenta**  
   Objeto con titular y saldo, con métodos para ingresar, extraer e informar estado.

3. **Rectángulo**  
   Objeto con alto y ancho, métodos para modificar propiedades, mostrar datos, calcular área y perímetro.

4. **Productos**  
   Creación de varios objetos producto, almacenamiento en array y muestra de datos.

5. **Persona**  
   Objeto con datos personales y métodos para mostrar generación, mayoría de edad, datos completos y generación de DNI.

6. **Libros**  
   Objetos libro con método para mostrar información y comparación por cantidad de páginas.

7. **Agenda telefónica**  
   Agenda de contactos con operaciones de alta, búsqueda, eliminación, listado y control de capacidad.

## Estructura

Los ejercicios se encuentran organizados dentro de la carpeta `js`.

## Rama de trabajo

El desarrollo se está realizando sobre la rama `dev`, dejando `main` para versiones más consolidadas.
